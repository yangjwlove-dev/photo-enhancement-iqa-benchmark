# Open Image Enhancement, Deblurring & Pixel-Art Scaling Baseline Dataset (v1.0.0)

[![License: CC BY 4.0](https://img.shields.io/badge/Dataset-CC_BY_4.0-lightgrey.svg)](./LICENSE)
[![Code License: MIT](https://img.shields.io/badge/Scripts-MIT-blue.svg)](./LICENSE)

A reproducible, 100% Public Domain / CC0-sourced benchmark dataset of **40 paired before/after images** across **6 restoration and scaling tasks**, evaluated exclusively with **deterministic local open-source baseline algorithms** (zero paid API calls, zero proprietary models) and a deterministic open-source Image Quality Assessment (IQA) pipeline.

> **Scope & Academic Honesty Statement**: All 40 `images/after/` outputs in this release are generated locally using open-source classical image processing routines (`OpenCV`, `Pillow`, `scikit-image`, `NumPy`). None of the outputs are generated by or claimed to represent cloud neural models. This dataset establishes transparent, reproducible lower-bound baselines for comparing classical signal-processing methods against modern neural restoration pipelines.

- **Total samples**: `40` verified CC0 / Public Domain source images (`0` commercial stock images, `0` modern portraits)
- **Controlled reference pairs**: `22` samples with ground-truth `images/reference/` (`upscale_2x`, `upscale_4x`, `deblur_jpeg`)
- **Archival & sprite pairs**: `18` natural/native inputs (`old_photo_denoise`, `historical_text_clarity`, `pixel_art_upscale`)
- **Metric backend**: Deterministic open-source suite (`scikit-image` PSNR/SSIM, `OpenCV` Laplacian variance & Tenengrad gradient energy, `NumPy` RMS contrast & Shannon entropy, and `Pillow`/`NumPy` exact pixel-art palette & RGBA alpha verification)
- **Related reference tools**: The `pixel_art_upscale` integer 4x nearest-neighbor baseline is algorithmically equivalent to the client-side browser tool [enhancephoto.org/pixel-art-upscaler](https://enhancephoto.org/pixel-art-upscaler). For tasks requiring learned neural priors (high-factor texture super-resolution, archival photo restoration, and blind deblurring/artifact removal), online reference implementations are available at [enhancephoto.org/image-upscaler](https://enhancephoto.org/image-upscaler), [enhancephoto.org/photo-restoration](https://enhancephoto.org/photo-restoration), and [enhancephoto.org/make-blurry-image-clear](https://enhancephoto.org/make-blurry-image-clear).

## Summary of Empirical Baseline Results (`n = 40`)

All 40 samples—including negative and regression cases—are retained in [`data/metrics_iqa.csv`](./data/metrics_iqa.csv) and aggregated in [`data/summary.json`](./data/summary.json).

| :--- | :---: | :--- | :--- |
| `old_photo_denoise` | 8 | `opencv_fastnlmeans_clahe` | Laplacian Var Δ `+1657.94` / `+1245.54`; Entropy Δ `+0.16` / `+0.11` bits |
| `upscale_2x` | 8 | `lanczos_2x_unsharp` | vs Bicubic 2x: PSNR `30.46→31.15 dB` (`+0.68 dB`), SSIM `0.8719→0.8931` (`+0.0212`) |
| `upscale_4x` | 8 | `lanczos_4x` | vs Bicubic 4x: PSNR `24.21→24.41 dB` (`+0.20 dB`), SSIM `0.6826→0.6941` (`+0.0115`) |
| `deblur_jpeg` (Gaussian Blur) | 3 | `wiener_unsharp_deblur` | PSNR `21.26→21.98 dB` (`+0.73 dB`), SSIM `0.4843→0.5617` (`+0.0774`) |
| `deblur_jpeg` (JPEG Q30) | 3 | `opencv_nlm_deblock` | **Negative result retained**: PSNR `30.36→29.69 dB` (`-0.67 dB`), SSIM `0.8478→0.7975` (`-0.0503`) |

### Notable Boundary & Negative Cases

1. **JPEG Q30 Deblocking Regression (`028`–`030`)**: Applying generic spatial Non-Local Means (`h=7`) to JPEG Q30 compressed satellite/landscape images over-smoothed legitimate fine terrain texture, reducing PSNR (`-0.32` to `-1.18 dB`) and SSIM (`-0.0389` to `-0.0699`). These rows are preserved intact to demonstrate why blind spatial smoothing cannot match DCT-aware or learned JPEG restoration.
2. **4x Upscaling Ceiling (`020`, `022`)**: While `lanczos_4x` improves mean PSNR by `+0.20 dB` over naive Bicubic 4x, two smooth-gradient artworks (`020`, `022`) exhibit slight SSIM drops (`-0.0028`, `-0.0008`) due to Lanczos ringing, and overall 4x SSIM remains low (`0.6941` mean), illustrating the physical information ceiling of non-learned interpolation.
3. **No-Reference Sharpness Caveat**: In `old_photo_denoise` and `historical_text_clarity`, CLAHE + UnsharpMask raises Laplacian variance and Tenengrad energy, which reflects both improved structural/print contrast and amplified archival paper grain.

## Repository Structure

- `data/samples.csv` — Master manifest of all 40 samples with provenance URLs, verified CC0/PD licenses, degradation types, baseline method names, and SHA-256 hashes (`before_sha256`, `after_sha256`, `reference_sha256`).
- `data/metrics_iqa.csv` — Per-sample before/after objective metrics and deltas for all 40 rows.
- `data/summary.json` — Category-level mean/median statistics, `deblur_jpeg` subgroup breakdowns, and SHA-256 checksums for key data and script files.
- `images/reference/` — 22 normalized lossless PNG ground-truth images (dimensions divisible by 4) for controlled degradation tasks.
- `images/before/` — 40 input images (18 native archival scans/sprites + 22 deterministically degraded images).
- `images/after/` — 40 deterministic local open-source baseline outputs.
- `DATA_DESCRIPTOR.md` & `DATA_DESCRIPTOR.pdf` — Full technical data descriptor (methodology, provenance, empirical findings, limitations, and ethics).
- `scripts/` — End-to-end reproducible Python pipeline (`fetch_sources.py`, `make_degraded.py`, `run_baselines.py`, `verify_licenses.py`, `compute_iqa.py`, `build_descriptor_pdf.py`).

## Reproduce Locally

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 1. Regenerate controlled degraded inputs from images/reference/
python scripts/make_degraded.py --update-csv

# 2. Regenerate all 40 local open-source baseline outputs
python scripts/run_baselines.py --update-csv

# 3. Verify all 40 licenses, resolutions, and SHA-256 hashes
python scripts/verify_licenses.py

# 4. Recompute objective IQA & pixel-art metrics + summary.json
python scripts/compute_iqa.py
```
